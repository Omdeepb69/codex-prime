# **Codex Prime** 🤖✨

## DESCRIPTION

Think of me as your personal JARVIS, but for your GitHub repos. Talk code, get answers, make changes – all from your terminal using natural language. Straight fire. 🔥

## FEATURES

Need the lowdown? Here's what this bad boy can do:

*   **Interactive Terminal UI:** Browse your GitHub kingdom like a boss with arrow keys. No cap. 👑
*   **Context-Aware Code Analysis:** I scan your repo, feed it to the Gemini brainiac 🧠, and actually *get* your code.
*   **Conversational Code Interaction:** Ask me anything about your code. Need an explanation? Want a new snippet? Bet. 😎
*   **AI-Powered Code Shenanigans:** Tell me to tweak your code (one file at a time for now, chill) or run scripts. Output? Right here. 🚀 (*Handle with care, obvs*).
*   **Automated Git Workflow:** Commit? Push? Branch? PR? Just say the word (or type 'Y'). Easy peasy. ✅

## LEARNING BENEFITS

Level up your AI game! You'll learn agent design, LLM wrangling (Gemini edition), API magic (GitHub!), slick terminal UIs, dev workflow automation (Git), and keeping AI chats on track. Basically, build your own code sidekick. 🛠️

## TECHNOLOGIES USED

The secret sauce includes:

*   `google-generativeai` (The brains behind the operation 🧠 - Gemini)
*   `PyGithub` (Chatting with GitHub 🐙)
*   `gitpython` (Local Git whispering 🤫)
*   `prompt_toolkit` or `blessed` (Making the terminal look fly ✨)
*   `python-dotenv` (Keeping secrets safe 🔒)
*   `subprocess` or `docker-py` (Running code safely... *mostly* 🤞 - **Use wisely!**)

## SETUP AND INSTALLATION

Alright, let's get this show on the road. Pop open your terminal:

```bash
git clone https://github.com/Omdeepb69/codex-prime.git
cd codex-prime
pip install -r requirements.txt
```

## USAGE

Fire up the main script. Tweak `config.json` if you're feeling fancy. ⚙️

```bash
python src/main.py
```
